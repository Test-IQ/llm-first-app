# Lab 6 — My First LLM Application

A beginner-friendly, LLM-powered REST API built with **Python**, **FastAPI**, and **Google Gemini**.

This project demonstrates how to connect a Python application to a Large Language Model (LLM), send a prompt, and return the generated response through an HTTP API.

## Features

- FastAPI application with interactive API documentation.
- Google Gemini integration using the official `google-genai` SDK.
- Environment-variable configuration for API credentials.
- Request validation using Pydantic.
- Basic error handling for API and service errors.
- Poetry for dependency management and project isolation.

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Application programming language |
| FastAPI | REST API framework |
| Google Gemini | Large Language Model |
| Google GenAI SDK | Gemini API integration |
| Poetry | Dependency and virtual environment management |
| Uvicorn | ASGI development server |
| python-dotenv | Loading environment variables |

## Prerequisites

- Python 3.14 or a compatible Python version.
- Poetry installed.
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey).

## Installation

Clone the repository or open the project folder, then install the dependencies:

```powershell
poetry install --no-root
```

The `--no-root` option installs the project dependencies without trying to install the application itself as a Python package.

## Configuration

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Replace the example value with your own Gemini API key.

**Security:** Never commit your `.env` file or publish your API key. The `.gitignore` file excludes it from Git.

## Running the Application

Start the FastAPI development server:

```powershell
poetry run uvicorn main:app --reload
```

The application will be available at:

- API root: http://127.0.0.1:8000/
- Interactive API documentation: http://127.0.0.1:8000/docs

## Testing the Chat Endpoint

Open the interactive API documentation at:

http://127.0.0.1:8000/docs

Find `POST /chat`, select **Try it out**, and submit:

```json
{
  "message": "Explain artificial intelligence in simple words."
}
```

The API sends the message to Google Gemini and returns the generated response.

Example response structure:

```json
{
  "model": "gemini-3.5-flash-lite",
  "response": "Artificial Intelligence is..."
}
```

The actual response text will vary depending on the prompt and model output.

## API Endpoint

### `GET /`

Returns a welcome message confirming that the application is running.

### `POST /chat`

Accepts a user message and returns a response generated by Google Gemini.

Request body:

```json
{
  "message": "Your question goes here"
}
```
